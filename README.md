## Descrição do Projeto
O projeto foi desenvolvido em C e é dividido em duas partes que, em sua essência, diferem nos Datasets utilizados: o primeiro dataset é o utilizado por todos os grupos da disciplina (NASA) e o segundo sobre a catalogação de desmatamento da Amazônia (DETER). O projeto consiste em um sistema que faz a leitura do dataset indicado e registra as linhas em uma estrutura de dados. Depois, faz uma consulta nestes dados registrados, selecionando de acordo com as especificações e filtros indicados pelo usuário. Ao final da execução, produz um arquivo de saída com as linhas do resultado da pesquisa.  
O sistema é dividido em camadas de leitura do arquivo csv e inserção na estrutura de dados, leitura do arquivo de busca e efetuação do filtro, escrita do arquivo de saída, TADs das estruturas de dados e a main, que controla tudo e determina o fluxo. Foi desenvolvida uma TAD adicional que engloba as outras estruturas de dados e que, por meio de parâmetros, faz todas as ações para qualquer estrutura de dados.
